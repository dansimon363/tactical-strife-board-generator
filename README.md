# tactical-strife-board-generator

This [app](https://dansimon363.github.io/tactical-strife-board-generator/) is a board generator for the [Tactical Strife](https://www.thegamecrafter.com/games/tactical-strife) board game.

Tactical Strife is a turn-based strategy board game for 2 - 4 players. Tactical Strife is a game of war that takes place over land, sea, and air. In order to raise enough cash to buy units, you must capture and/or build factories, ports, and airports. During the game, victory points are earned by building units, controlling factories/ports/airports, and capturing enemy headquarters. The object of the game is to have the most victory points at the end of the game.
